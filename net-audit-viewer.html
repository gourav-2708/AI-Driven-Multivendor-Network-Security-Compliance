Quick Start

Generate a JSON report from the command line:

.\net-audit.exe --format json fixtures\cisco_sample.cfg > report.json

Then drag report.json onto the drop zone above.

For the full web dashboard with file upload, audit history, and live auditing, run:

.\webapp\start.ps1
